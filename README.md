# SLA-Processing-Rate-for-Germany
This SQL query shows the percentge of orders that were in line with the Service Level Agreements. 
Since this was a report that was needed on short notice, it was created in Snowflake using the available resources, which is why dynamic solutions for bank holidays and carrier cutoff times could not be included. This code uses several CTE Tables to calculate the percentage of orders that were processed in time. 
All information about Carriers, cutoff etc. are changed or fictitious for confidentiality reasons.
